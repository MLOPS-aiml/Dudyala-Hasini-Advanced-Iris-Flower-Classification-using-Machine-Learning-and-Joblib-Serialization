# 🌸 IrisVision AI

## Advanced Iris Flower Classification System


## 📌 Project Overview

IrisVision AI is an AI-powered web application
for Iris flower classification using Machine Learning.


## 🚀 Features

- User Authentication
- ML Based Prediction
- Dataset Explorer
- Data Analytics
- Explainable AI
- MLOps Monitoring Dashboard


## 🤖 Machine Learning Model

Algorithm:

Random Forest Classifier


Dataset:

Iris Dataset


## 🛠 Technologies

- Python
- Streamlit
- Scikit-Learn
- Pandas
- Plotly


## ▶️ Run Application

Install requirements:

pip install -r requirements.txt


Run:

streamlit run app.py


## 📊 Modules

1. Login/Register
2. Prediction
3. Analytics
4. Explainable AI
5. MLOps Dashboard
